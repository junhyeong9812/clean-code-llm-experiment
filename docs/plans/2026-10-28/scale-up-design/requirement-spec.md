## 0. 요구사항 원문 (인터뷰 기록)

- 원문: "진행하자" → N0 다음 결정 = **① 코드 규모 확장**(ADR-0005 §7.3 사전 지정 후보와 같음).
- Q/A:
  - 확장 방식 → **실제 기능 추가**(새 도메인 영역을 두 구조에 같은 동작으로, 행동 테스트·equiv로 동치 검증).
  - 낱말 겹침 → **겹치게 설계**(새 기능도 확정·정산·기한·취소 등 기존 과제 개념을 써서 grep 결과가 여러 곳으로 퍼지게. 두 구조에 같게 퍼졌는지 리뷰).
  - 진행 → **단계적 + 중간 게이트**(설계 ADR → 구현당 1만 줄 → T1·C2 재채택 + 파일럿 4회 → 통과 시 나머지 과제·본 실행, 미달 시 재결정).
  - 검증 강도 → **기존과 같은 수준**(기능마다 행동 테스트, 두 구조 응답·DB 대조. SQL·문장 로그 equiv는 배치·잠금 경로).
  - 크기 기준 → **god 1만 줄**(god 앱 소스 ≥ 10,000줄, `Marketplace.kt` 단일 파일 구조 유지. layered는 자연 증가).
  - 파일럿 과제 → **기존 T1·C2를 큰 코드로 이식**(같은 주입·같은 TASK.md — 크기만 다른 비교).
  - 이번 범위 → **설계 ADR만**(구현은 ADR 합의 뒤 기능 묶음별 별도 작업 폴더).
- 재합의(조사 결과 뒤, 2026-10-28 — 진행 방식 "구현당 1만 줄 → 파일럿"을 바꿈):
  - 분량 → **중간 게이트 추가**(후보 12개로는 god 약 5,800줄 추정 — 1차 파일럿을 god 약 6천 줄에서).
  - 고칠 곳 → **건드리지 않음**(C2 본보기 기능 제외). 시드 → **별도 난수·후처리**(기존 22테이블 불변).
  - 중간 게이트 통과 시 → **6천 줄에서 본 실행**(나머지 과제 4개 이식). 미달 시 → **턴이 늘었으면 계속**(어느 구조든 턴 중앙값 ≥ 7.5면 1만 줄로, 아니면 2차 결론 후 중단).

## 1. 목표·대상 (필수)

`docs/adr/0006-scale-up.md`가 생겨, 구현자가 그것만 보고 기능 묶음별 작업을 시작할 수 있으면 끝. 담을 것: 추가 기능 목록(묶음·순서·예상 줄 수), 기존 과제 낱말과의 겹침 지도, 스키마·시드 변경, 행동 테스트·equiv 범위, T1·C2 이식 방법, 단계와 게이트(중간 파일럿 판정·미달 시 분기), 비용 추정, 타당성 위협. ADR-0005·README·NEXT와 정합.

## 2. 경계·불변식 (필수)

- 처치 정의 유지: god = 절차 전체가 `Marketplace.kt` 1파일, layered = `api·service·domain·infra`. 두 구조 동작·SQL 동치(ADR-0004 계약 방식) 유지.
- 기존 동작 계약(ADR-0002~0004)과 기존 행동 테스트 211개·equiv 12개는 깨지 않는다 — 새 기능은 추가만.
- ADR-0005 §1 사전 기준(토큰 비 < 0.8 등)·§7.3 게이트(구조별 턴 중앙값 ≥ 10) 변경 금지 — 같은 게이트로 재측정.
- 낱말 겹침은 두 구조에 대칭이어야 한다(한 구조에만 미끼를 두지 않는다 — 위협 4 설계자 편향).
- 1차 결론(파일럿 결과)과 새 측정을 섞지 않는다 — 별도 사전 등록 단위.

## 5. 검증 방법 (필수)

- 사실 대조: ADR이 인용하는 현행 코드·스키마 위치(file:line)·줄 수는 실파일에서 확인(워커 조사 결과는 핵심 1~2개 메인 교차 확인).
- 설계 선검증: 신설 동작 불변식(새 기능 계약·낱말 대칭) 덩어리 점검.
- 듀얼 1패스(Opus 워커 ∥ codex) — 렌즈: 구현 가능성·누락(스키마·시드·테스트·equiv)·대칭(설계자 편향)·ADR-0005 기준 보존·비용 현실성 → 종합 → 감사 → post-fix 재점검 1회.

## 8. load-bearing 가정

1. 실제 기능을 더해 god을 1만 줄로 키우면(낱말 겹침 포함) 에이전트 탐색 턴이 늘 여지가 있다 — 미검증, 중간 게이트가 이를 판정한다.
2. 두 구조에 같은 동작으로 기능을 추가하는 비용이 이전 단계(god·layered 1·2단계)와 비슷한 규모로 감당 가능하다 — ADR 비용 추정에서 확인.
