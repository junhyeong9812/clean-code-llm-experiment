## 2. 경계·불변식 (필수)

- 결론 문장은 ADR-0005 §7.3 개정 2의 사전 결정 문장 그대로(결과 본 뒤 바꾸지 않음): "이 코드 크기에서는 Sonnet이 두 구조 모두 쉽게 풀어, 구조 효과를 볼 만큼 과제를 어렵게 만들기 어렵다."
- **구조 효과(god vs layered)에 대한 주장 금지** — 파일럿은 본 표본이 아니고 n=1. 수치는 관찰로만, 구조 간 비교 문장은 "비교 불가"로.
- 범위 문구 필수: Sonnet · 수정 과제(T1·C2 파일럿) · 구현당 2.7k~4.8k줄 · 사전 등록 요약과 다른 추정 대상.
- 모든 수치는 원자료(`experiment/results-pilot/runs.jsonl`·`results-pilot2/runs.jsonl`·checks.jsonl·두 작업 log)에서 재추출 — 메모리 재현 금지.
- 다음 결정은 후보 나열만, 권장·선택하지 않는다.
