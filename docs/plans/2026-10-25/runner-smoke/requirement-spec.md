## 1. 목표·대상 (필수)

`experiment/runner/`에 러너를 만들고 더미 과제로 스모크해 끝낸다. 러너는 (과제, 구조, 모델, 반복) 하나를 ADR-0005 §6대로 실행한다. 순서는 다음과 같다.

1. 작업 사본 조립
2. 실행 전용 도커 네트워크에 1k 시드 DB와 가짜 PG jar 컨테이너 기동
3. 에이전트 컨테이너에서 `claude -p … --output-format stream-json` 실행(시간 상한, 강제 종료 포함)
4. 이벤트 저장과 파싱(modelUsage 토큰, 턴, 읽은 줄, 심볼 겨냥 접근, 첫 편집 위치), 입력 감사
5. `runs.jsonl` 1행 기록과 정리

여러 조건을 병렬 3으로 돌리는 진입점과 재개(valid 행 건너뛰기)도 포함한다. 판정 단계는 자리(훅)만 두고 구현하지 않는다.

## 2. 경계·불변식 (필수)

- **격리:** 에이전트 컨테이너의 마운트는 세 가지뿐이다: 그 실행의 작업 사본(`/work`, rw), 전용 Gradle 캐시(ro), 실행 전용 격리 HOME(rw). 이벤트는 마운트 없이 컨테이너 stdout으로 받는다. *(리뷰 루프 1 보정 — 처음엔 '이벤트 출력 위치' 포함 네 가지였으나 더 좁게 구현)* 외부 접속은 `--internal` 실행 네트워크 + 허용 목록 프록시(api.anthropic.com)로만 — 거부된 접속 시도는 무효. *(사용자 결정 2026-10-26, 리뷰 루프 3 — 입력 감사는 보조)* 실험 저장소·oracle·다른 실행 사본·사용자 HOME은 마운트하지 않는다. 러너는 기동 전에 마운트 목록을 이 허용 목록과 대조하고, 다르면 시작하지 않는다.
- **로그인 파일:** 실행마다 사본을 격리 HOME에 넣는다. 만료가 가까우면(앞 실험: 45분) 갱신될 때까지 기다린다. 실행 뒤 사본의 만료가 원본보다 늦을 때만 flock과 임시 파일 + rename으로 원본을 교체한다. 토큰 값은 로그·이벤트 보관·runs.jsonl·대화에 남기지 않는다.
- **측정 정직성:** 토큰은 `result.modelUsage` 합계(input + output + cacheRead + cacheCreation, 하위 에이전트 포함)다. `result`가 없으면(시간 상한 강제 종료) assistant 이벤트 usage 합을 부분 토큰으로 두고 `censored`로 표시한다. 시도마다 runs.jsonl에 행이 생긴다. 무효도 사유(감사·인프라·사용량 한도·러너 예외)와 출력 꼬리를 남기며, 무음으로 빠지는 시도는 없다.
- **정리:** 정상·예외·SIGINT·SIGTERM 어느 경우에도 그 실행의 컨테이너 3개와 네트워크를 지운다. 작업 사본은 diff만 보관하고 지운다. 보관 위치는 어떤 에이전트 컨테이너에도 마운트하지 않는다. 여유 디스크가 10GB 미만이면 시작하지 않는다.
- **하네스 미로드:** 컨테이너의 claude가 사용자 CLAUDE.md·훅·플러그인을 읽지 않는다(스모크로 확인).
- **재현성:** 이미지 태그에 CLI 버전을 넣고, 실행 행에 이미지 id·CLI 버전·모델을 기록한다.

## 5. 검증 방법 (필수)

- **단위 테스트(unittest, 실제 실행 없음):**
  - 파서: stream-json 고정 입력(스모크 캡처 + 합성)으로 modelUsage 합, result 없을 때 부분 usage, message.id 기준 턴 수, 읽은 줄, 겨냥 접근(offset Read·Grep 줄·Edit, 전체 Read는 따로), 첫 편집 위치를 확인한다.
  - 감사: 금지 경로와 금지 명령 검출, 도구 결과는 보지 않는지를 확인한다.
  - 재개: valid 행은 건너뛰고 무효만 다시 도는지를 확인한다.
  - 로그인 파일: 만료가 늦을 때만 되쓰고 원자 교체하는지, 동시 실행 flock을 확인한다.
  - 마운트 허용 목록: 허용 목록 밖 마운트를 거부하는지를 확인한다.
- **blind 테스트 워커:** 이 명세와 ADR §5·§6만 보고(구현 diff는 열람하지 않음) 파서·감사 테스트를 따로 쓴다.
- **인프라 스모크(무료):**
  - 에이전트 대신 셸 명령으로 같은 컨테이너를 돌린다. 마운트 목록, DB·가짜 PG 접속, 외부 네트워크 접속, 호스트 경로 부재, Gradle 오프라인 빌드(`/work`의 god 앱 `bootJar`)를 확인한다.
  - 병렬 3에서 네트워크·이름 충돌이 없는지, 중단(SIGINT) 뒤 잔여 컨테이너·네트워크가 0인지를 확인한다.
- **에이전트 스모크(Haiku ≤3회):**
  - ① 하네스 미로드: 암호 단어 방식이다. 사용자 CLAUDE.md에는 손대지 않고, 격리 HOME 밖의 로그인 계정 설정이 섞이지 않는지를 init 이벤트와 응답으로 본다.
  - ② 더미 과제: 사본 안 파일 수정 + `test.sh`(DB 조회) 통과. modelUsage·턴·감사 행이 나오는지 본다.
  - ③ 짧은 시간 상한(예: 60초) 강제 종료: censored와 부분 토큰, 정리를 본다.
  - 각 회 로그인 원본의 만료 전후를 기록한다.
- 머지 전 안전선(core §4): 스모크, 테스트, diff self-review, 반증 질문.
- 리뷰: 듀얼 리뷰 루프(≤3).

1. 컨테이너 안 claude 2.1.308이 복사한 `.credentials.json`으로 구독 인증되고, 호스트와 같은 stream-json 이벤트(`result.modelUsage`)를 낸다. task 01 직후 Haiku 스모크 ①로 실증한다(실패하면 설계 재검토).
2. Gradle이 읽기 전용 의존성 캐시(`GRADLE_RO_DEP_CACHE`)로 컨테이너 안에서 오프라인 빌드된다. 인프라 스모크로 실증한다.
