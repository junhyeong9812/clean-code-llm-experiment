# 측정 로그 (Measurement Log)

> 작업당 1행, <1분. 하네스 규칙 증감(core §0-3)은 이 데이터를 근거로 한다.
> 위치: 대상 프로젝트 `docs/measurement-log.md`.

## 스키마 규칙 (파싱 가능성 — 2026-07-03 정비)

- **고정 12열**(아래 표 순서 그대로). 열을 합치거나 빼지 않는다 — 없으면 `-`.
- **작업명·내용에 `|`·개행 금지** — `|`는 `∣`(U+2223) 또는 "or"로, 개행은 공백으로. (열 밀림·표 단절 방지)
- **단위 enum**: 총 소요·오버헤드 = `~Nm`(분) 또는 `~Nh`(시간) 정량 우선. 정성(`중`·`큼`)은 정량 불가 시만.
- **stakes enum**: `낮음` / `중간` / `높음` (혼합 표기 금지 — 승격됐으면 최종값 1개).
- **소급/미측정**: 실시간 측정 못 한 필드는 `소급` 또는 `미측정` (빈칸·추정 금지).
- **표는 하나로 유지** — 각주·목록 아래 새 행을 이어붙이지 않는다(표가 쪼개져 파싱 파손).
- 기존 로그(2026-07-03 이전)는 read-only — 이 스키마로 소급 변환하지 않는다(신규 행에만 적용).
