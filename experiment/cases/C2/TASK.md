# 판매자 패널티 조회 API 추가

판매자가 자기 패널티(판매자 귀책 — 발송 기한 초과·검수 불합격 때 생기는 패널티)를 볼 수 있는 API가 없다. 아래 계약대로 새 API를 추가하라. 기존 API의 동작은 바꾸지 않는다.

## 계약

`GET /me/penalties`

- **인증:** `X-User-Id` 헤더(다른 `/me/...` API와 같다). 헤더가 없거나, 숫자가 아니거나, 없는 사용자면 **401** `{"code": "UNKNOWN_USER", "message": "..."}` — 기존 API와 같은 오류 형식이다.
- **응답:** 200, JSON 배열. 원소 하나가 패널티 하나다.

  ```json
  [
    {
      "penaltyId": 123,
      "orderItemId": 4567,
      "amount": 3000,
      "createdAt": "2026-10-01T00:00:00+09:00",
      "settled": false
    }
  ]
  ```

  | 필드 | 타입 | 뜻 |
  |---|---|---|
  | `penaltyId` | 정수 | 패널티 id |
  | `orderItemId` | 정수 | 그 패널티가 생긴 주문 항목 id |
  | `amount` | 정수(원) | 패널티 금액 |
  | `createdAt` | 문자열 | 패널티가 생긴 시각. 다른 API와 같은 형식(KST 오프셋을 붙인 ISO-8601, 예 `2026-10-01T00:00:00+09:00`) |
  | `settled` | 불리언 | 그 패널티가 주간 정산(`weekly-settlement`)에 이미 반영되었으면 `true`, 아직이면 `false` |

- **범위:** 요청한 사용자가 판매자인 패널티만. 다른 사용자의 패널티는 보이지 않는다.
- **정렬:** `createdAt` 내림차순(최신 먼저). `createdAt`이 같으면 `penaltyId` 내림차순.
- **빈 목록:** 패널티가 없는 사용자(판매한 적이 없는 사용자 포함)는 200 `[]`.
